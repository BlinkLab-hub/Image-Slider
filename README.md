# Image Slider

A responsive image slider built with **HTML**, **CSS**, and **JavaScript**.

This is a simple project that displays one image at a time and lets the user move through a collection of images using previous and next buttons.

## How It Works

The slider works by keeping track of the current image index.

1. All images are loaded into the page.
2. Only the active image is displayed.
3. The previous and next buttons change the image index.
4. When the index reaches the beginning or end, it loops back around.
5. A slide animation is added when switching between images.
